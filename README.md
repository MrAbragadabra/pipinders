# PIPINDERS — Winter Voxel Weather Edition 2026

Организованная зимняя версия сайта PIPINDERS в Minecraft-стиле, для GitHub Pages и домена `pipinders.ru`. HTML, CSS и JavaScript без сборки, фреймворков или дополнительного хостинга сайта. Исходные цвета: `#54fc54` и `#c0f1c0`.

## Что изменилось

Только расположение файлов и их ссылки: перенесены CSS, JS, иконки и изображения, исправлены `href`, `src`, абсолютные SEO-ссылки на `og-image.png` и пути иконок в `site.webmanifest`. Добавлены `.editorconfig`, `.gitignore` и этот README. В самом коде CSS/JS, в SVG, формах, конфигурации заявки и ресурспаке **ничего не изменено**. Порядок подключения стилей и скриптов сохранён.

## Публикация на GitHub Pages

1. Создайте резервный коммит/ветку текущей зимней версии сайта.
2. **Удалите старые корневые файлы** `styles.css`, `winter.css`, `minecraft.css`, `weather.css`, `script.js`, `winter.js`, `weather.js`, `form-config.js` и старые файлы в `assets/` (`favicon.svg`, `favicon-32.png`, `apple-touch-icon.png`, `winter-world.svg`, `house-light.svg`, `og-image.png`). Они уже находятся в новых папках. Если применяете полный архив в чистый репозиторий, ничего удалять не нужно.
3. Распакуйте содержимое архива в корень публикуемой ветки (`main` или зимняя ветка, в зависимости от настроек Pages); `index.html`, `CNAME`, `.nojekyll`, `robots.txt`, `sitemap.xml` и `site.webmanifest` должны лежать **в корне**.
4. После публикации откройте сайт и проверьте отсутствие 404 в браузерной вкладке Network, работу гирлянды, снега, таймера, CAPTCHA, освещения домика, ссылок и формы.
5. При обновлении CSS/JS можно изменить версию `?v=` в `index.html`, чтобы сбросить клиентский кеш. Для этого переноса адреса файлов уже изменились, поэтому старые кешированные URL не используются.

Адрес ресурс-пака остался прежним: `https://pipinders.ru/resources/BACAP.zip`.

## Функции и настройки

- **Гирлянда:** каждая лампочка переключается отдельно; общая кнопка управляет всей гирляндой. Настройки хранятся в браузере.
- **Снег:** один Canvas, занимающий лишь видимую область; до 24 пиксельных снежинок на телефоне и до 56 на десктопе. Не мешает нажимать кнопки и отключается переключателем.
- **Снег на надписи «СКОРО»:** ограниченное накопление; встряхивание нажатием или с клавиатуры.
- **Освещение домика:** по московскому времени (UTC+3): день 08:00–16:59, вечер 17:00–19:59, ночь 20:00–05:59, рассвет 06:00–07:59.
- **Форма заявок:** адрес `apply@pipinders.ru`, Yandex Cloud Function, SmartCaptcha. `js/form-config.js` намеренно подключён **до** `js/main.js`, сохранив текущий порядок работы.
- **Запуск сервера:** 19 декабря 2026 в 14:00 МСК, Minecraft Java Edition 26.3, только лицензия.

**Безопасность:** `js/form-config.js` — публичный файл и может содержать только доступные браузеру параметры (например, URL API и клиентский ключ SmartCaptcha). Не добавляйте SMTP-пароли, секретные ключи или токены сервисного аккаунта в сайт, репозиторий и архив.

## Локальная проверка

Из корня проекта выполните `python -m http.server 8000`, затем откройте `http://localhost:8000`. Этот сервер нужен только для локального просмотра; GitHub Pages сам раздаёт статические файлы.

Если проверяете форму на локальном домене, облачная CAPTCHA может требовать настройки разрешённых доменов. Реальную доставку письма нужно тестировать на опубликованном домене — данный рефакторинг не меняет серверную функцию или почту. Специальный мониторинг онлайн-игроков в данной исходной зимней версии отсутствует.
