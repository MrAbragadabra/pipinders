# PIPINDERS — Winter Voxel Weather Edition 2026

Декабрьская Minecraft-версия сайта с эффектами погоды. Готова к размещению на GitHub Pages без сборки и дополнительных API.

## Новые эффекты

**Освещение дома** зависит от московского времени (UTC+3), как и таймер запуска сервера:

| МСК | Сцена | Свет в окнах |
|---|---|---|
| 06:00–07:59 | Рассвет | Тусклый |
| 08:00–16:59 | День | Выключен |
| 17:00–19:59 | Вечер | Тёплый |
| 20:00–05:59 | Ночь | Яркий |

Сцена обновляется раз в минуту и когда вкладка снова становится активной. Это локальная анимация CSS и клиентский JavaScript: посещение сайта не создаёт сетевых запросов.

**Снег** теперь падает по **всему сайту при прокрутке**: один фиксированный Canvas размером с видимую область браузера, а не с многометровую страницу. Максимум 24 пиксельные снежинки на телефоне, 56 на компьютере; отрисовка примерно 20 и 24 кадра в секунду соответственно. Выключается прежней кнопкой «СНЕГ», настройки продолжают храниться в `localStorage`. Не перекрывает нажатия.

**Надпись «СКОРО»** постепенно получает тонкую пиксельную снежную шапку (не более примерно 8 пикселей). Нажми/тапни по самому слову или используй клавиатуру (Enter/Пробел), чтобы стряхнуть снег. Снежинки осыпаются, снежная шапка со временем появляется снова. Вся анимация размещена поверх заголовка и не изменяет поток документа.

## Файлы

Изменены из Winter Voxel Edition:
- `index.html` — слои окна, снег на всём экране и интерактивная надпись.
- `winter.js` — лёгкая отрисовка снега в окне браузера, все прежние функции гирлянды сохранены.
- `script.js` — одно изменение: остановлен **невидимый** старый Canvas-эффект из первоначальной версии сайта, который ранее продолжал рендериться за кадром.
- `assets/winter-world.svg` — дневные окна стали затемнёнными, чтобы свет действительно менялся.

Добавлены:
- `weather.css`, `weather.js` — освещение по Москве и снежная шапка на слове «СКОРО».
- `assets/house-light.svg` — отдельный пиксельный слой света для окон дома.

Не тронуты `form-config.js`, правила, форма, `winter.css`, `minecraft.css`, `styles.css`, `CNAME`, SEO-метаданные, ресурс-паки и механика лампочек.

## Как выложить

Для отдельной публикации в декабре распакуй **полный ZIP** в корень репозитория GitHub Pages; обязательно сохранить `.nojekyll`.
Для обновления предыдущей Winter Voxel Edition достаточно **ZIP-патча**, заменив перечисленные изменённые файлы и добавив новые. В версии `index.html` указаны обновлённые параметры `?v=` для скриптов и стилей.

Сохрани текущий рабочий сайт в ветке перед публикацией. При настройке живой функции Yandex Cloud отдельно проверь форму на домене после развёртывания.

## Оптимизация и доступность

- При `prefers-reduced-motion: reduce` отключаются анимированный снег, снежные шапки и встряхивание; освещение дома по времени продолжает меняться без анимационного перехода.
- При включённом `Save-Data` снег по умолчанию выключен.
- Canvas имеет плотность 1 пиксель (без масштабирования под Retina), снежинки квадратные, без теней и фильтров размытия.
- Нет новых шрифтов, JS-библиотек, серверов, файлов куки, сетевых API или фоновых сетевых запросов.
- Доступ к «стряхиванию» через клавиатуру и текстовую подпись для скринридера.
- JavaScript основной формы и служебные данные заявителей не затрагиваются.

Локально проверен в Chromium на ширинах 320/390/768/1440 px, включая реакции гирлянды, выключение снега, прокрутку и режим пониженной анимации. Настоящие Safari/Android и отправку реальной заявки надо проверить на опубликованном сайте.
