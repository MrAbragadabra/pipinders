# PIPINDERS — как добавлять скриншоты в «Летопись»

**README.md намеренно не изменён.** Это отдельная инструкция по галерее.

## Один раз: включить автоматическую публикацию

1. Загрузить содержимое обновлённого архива в корень репозитория. Файлы `.github/workflows/deploy-pages.yml` и `scripts/build_gallery.py` должны находиться в своих папках.
2. В GitHub открыть **Settings → Pages → Build and deployment → Source → GitHub Actions**. Ранее использовавшийся вариант `Deploy from a branch` надо заменить. Это обязательно: браузер не может читать список файлов из папки GitHub Pages самостоятельно.
3. В **Actions** проверить запуск `Publish PIPINDERS with season gallery`. При необходимости выполнить **Run workflow** для ветки по умолчанию. Публичный домен `pipinders.ru` проверить в настройках Pages; при необходимости снова указать его. DNS для почты трогать не нужно.

## Каждый следующий раз: только загрузи скриншоты

- Скриншоты 1-го сезона → `gallery/season-1/`
- Скриншоты 2-го сезона → `gallery/season-2/`
- Можно добавить, удалить или заменить файлы в этих папках. Имена любые, удобно `001.png`, `002.png`, ...; сортировка по числам в имени.
- Форматы: `.png`, `.jpg`, `.jpeg`, `.webp`. Не клади ZIP в папки галереи.
- Запушь файлы в **ветку по умолчанию**. GitHub Actions сам создаст `gallery/manifest.json`, оптимизированные WebP-миниатюры и опубликует сайт. HTML/CSS/JS менять не нужно.
- Для больших скриншотов полезно предварительно уменьшать размер файла. Оригиналы публично доступны при нажатии «ОРИГИНАЛ». Не загружай скриншоты с секретами, приватными чатами или личными данными без согласия участников.
- До загрузки фотографий страница показывает красивые пустые секции «СЕЗОН 01» и «СЕЗОН 02», а не выдуманные изображения.

## Локальная проверка (необязательно)

Если установлен Python и Pillow:

```bash
python -m pip install -r scripts/requirements-gallery.txt
python scripts/build_gallery.py
python -m http.server 8000
```

Открой `http://localhost:8000/gallery.html`. На GitHub сборка выполняется автоматически.

## Если снимков нет на опубликованном сайте

- Убедись, что GitHub Pages использует **GitHub Actions**, а не `Deploy from a branch`.
- В **Actions** проверь успешное выполнение `Publish PIPINDERS with season gallery`.
- Проверь, что файлы находятся ровно в `gallery/season-1/` или `gallery/season-2/` **в ветке по умолчанию**.
- На GitHub Pages и любые файлы в публичном репозитории распространяются ограничения размера и трафика GitHub. Не используй Git LFS для скриншотов, которые должен отдавать Pages напрямую.

Текущие страницы формы заявки, политики и согласия сохранены. Настройки Yandex Cloud не затронуты.
